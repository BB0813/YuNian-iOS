> 会话置顶/免打扰（G9/G10）、主题/字号（H8/H9）、备份恢复（H13）、

> 语音消息录音与播放（A11）、生图 API 设置页（D2）。
>
> **仍未做**（全部需要当前构建链做不到的东西或属大工程）：
> - 桌面小组件（J2）、灵动岛（J4）、分享扩展（J5）—— 都需要独立的
>   Extension target，当前 xtool/SwiftPM 构建链无法创建 target
> - iCloud 备份（J6）—— 需要 iCloud entitlement，免费签名不可用
> - 快捷指令（J3）—— AppIntents 可做但需真机联调 Shortcuts，本轮未排
> - 群聊（K1/K2）—— iOS 侧无群聊数据模型，属大工程
